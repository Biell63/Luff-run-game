# Jogo de Pulo - Luffy Run Game ☠️

Um jogo simples de pulo infinito onde você controla o Luffy pulando sobre ondas de água em uma praia paradisíaca.

## 🎮 Como Jogar

- Pressione qualquer tecla para fazer o Luffy pular
- Evite bater na água que se aproxima
- Quando bater na água, o jogo termina
- Clique em "Reiniciar Jogo" para jogar novamente

## 🎯 Objetivo

Sobreviva o máximo possível pulando sobre as ondas que se aproximam da esquerda para a direita.

## ✨ Características

- **Controles Simples**: Qualquer tecla do teclado faz o Luffy pular
- **Animações Suaves**: Animações CSS para pulos e movimento da água
- **Game Over Visual**: Quando o jogo termina, Luffy cai, a água aumenta e aparece uma tela de game over
- **Reinício Fácil**: Botão de restart permite continuar jogando sem recarregar a página
- **Tema Praia**: Cenário com fundo de praia paradisíaca

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da página
- **CSS3**: Estilização, animações e layout responsivo
- **JavaScript**: Lógica do jogo, detecção de colisão e controle de eventos

## 🚀 Como Executar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. Comece a jogar pressionando qualquer tecla!

## 🎨 Personalização

O jogo pode ser facilmente personalizado editando:
- **style.css**: Para alterar cores, tamanhos e animações
- **script.js**: Para modificar a velocidade, detecção de colisão ou adicionar novos recursos
- **imagens/**: Para trocar sprites e fundos

## 📝 Notas de Desenvolvimento

- O jogo usa `setInterval` para o loop principal de 10ms
- A detecção de colisão verifica a posição da água e do Luffy
- As animações são feitas com CSS keyframes
- O jogo é totalmente client-side, não requer servidor
